# Como funciona

O Interclasse do CEM Dom Marcelino de Milão é disputado em **mata-mata**: quem vence avança, quem perde está fora daquela competição.

São seis competições:

- Handebol Masculino
- Futsal Feminino
- Futsal Masculino
- Vôlei de Quadra Masculino
- Vôlei de Praia Masculino
- Vôlei de Praia Feminino

# Fases e vagas

- Cada jogo tem um número dentro da sua competição, como na tabela oficial.
- "Vencedor do jogo 1" quer dizer que a vaga é de quem ganhar o jogo 1.
- "Vencedor - direto" é uma vaga direta, definida pela organização.
- No **Futsal Masculino** haverá sorteio no dia para as fases seguintes.

# Futsal e handebol

- Vence quem fizer mais gols.
- Em caso de empate, o vencedor é decidido nos pênaltis (ou no desempate combinado pela organização).

# Vôlei

- Os jogos são em melhor de 3 sets: vence quem ganhar **2 sets**.
- Vôlei de quadra: sets de **25 pontos**.
- Vôlei de praia: sets de **21 pontos**.
- Set decisivo (3º set): **15 pontos**.
- Todo set precisa terminar com **2 pontos de diferença**.

# Ranking das turmas

- Cada vitória vale **3 pontos**; derrota vale 0.
- Desempate: mais vitórias, depois mais títulos e, por fim, ordem do nome da turma.
