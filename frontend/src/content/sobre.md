# O que é o InterCamp

O InterCamp é o aplicativo oficial do Interclasse do CEM Dom Marcelino de Milão. Ele mostra os jogos, os placares ao vivo, o chaveamento de cada competição e o ranking das turmas.

# Quem fez

O app foi criado pela turma **301 INT** nas aulas de programação, do desenho das telas até o servidor.

# Como foi feito

- Telas: React, Vite e Tailwind CSS
- Servidor: Node.js, Express e PostgreSQL
- Placar ao vivo: Server-Sent Events (o servidor avisa o celular quando algo muda)
